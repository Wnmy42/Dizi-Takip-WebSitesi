# Güvenlik

Güvenlik açığı bildirimlerinde hassas bilgileri issue, pull request veya başka bir herkese açık kanala yazmayın. Açığın yeniden üretimi için gerekli bilgileri, erişim anahtarlarını ve kişisel verileri kamuya açık paylaşmayın.

GitHub deposunda **Security > Report a vulnerability** seçeneği mevcutsa bildirimi bu özel kanal üzerinden gönderin. Bu seçenek yoksa, özel bir bildirim kanalı istemek için depo sorumlusu [@Wnmy42](https://github.com/Wnmy42) ile iletişime geçin; açığın ayrıntılarını herkese açık paylaşmayın.

Bildirimde etkilenen dosya veya bileşeni, etkiyi, yeniden üretim adımlarını ve mümkünse önerilen düzeltmeyi belirtin. Yanlışlıkla bir gizli anahtar paylaşıldıysa anahtarı derhal iptal edip yenileyin; anahtarı bildirime eklemeyin.
